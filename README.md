# Sandeep Explores

A modern orange-themed personal website for a travel, photography, and cinema storyteller.

## Included
- Responsive landing page
- Light/dark mode toggle
- Social-ready portfolio sections
- Article cards and feature blocks
- Sign in and sign up pages
- Local storage-based demo authentication

## Files
- `index.html` — main landing page
- `sign-in.html` — sign in page
- `sign-up.html` — sign up page
- `css/styles.css` — styling
- `js/script.js` — theme + auth logic

## Publish for free
### Netlify
1. Zip the project folder.
2. Open https://app.netlify.com/drop
3. Drag the folder into the upload area.
4. Netlify will publish a free public link.

### GitHub Pages
1. Push the project to a GitHub repository.
2. Open repository settings.
3. Select Pages.
4. Use the root folder or a docs folder.
5. Publish the site.

## Customize later
- Replace placeholder images with your own photos.
- Update article titles and copy.
- Replace sample contact links.
- Add a real backend later with Supabase or Firebase if you need true authentication.
